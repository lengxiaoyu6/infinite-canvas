# 待测试

## 视频生成任务轮询

- [ ] Grok 视频任务创建后，上游短暂返回 `unknown` 时，后台继续查询任务状态，完成后创作台显示视频地址和 100% 进度。
- [ ] 超过 30 分钟仍未完成的视频任务，后台再查询一次后标记失败，创作台停止持续查询。
- [ ] 创作台存在多条生成中记录时，每轮最多查询 4 条任务，页面滚动和操作保持流畅。

## 注册用户生图对象存储

- [ ] 注册用户使用云端渠道或个人密钥渠道生成图片后，任务结果自动保存到账号对象存储或管理员允许的全局对象存储，并返回 `server:<id>` 存储键。
- [ ] 账号对象存储未配置或上传失败时，图片任务仍保持完成状态，并保留上游图片地址供读取。
- [ ] 注册用户重新登录或更换设备后，生成记录能够通过 `server:<id>` 读取已保存图片。

## 画布音频任务存储

- [ ] 注册用户生成音频时优先保存到账号对象存储或管理员允许的全局对象存储；存储未配置或上传失败时，任务仍保持完成并返回内嵌音频地址。

## WebDAV 森络盘直链

- [ ] WebDAV 配置森络盘 API 地址和访问令牌后，上传图片返回 `https://.../f/...` 长期直链。
- [ ] 视频生成完成后，创作台等待服务端上传完成；上传成功时生成记录保存为 `server:<id>` 与森络盘长期直链。
- [ ] 视频服务端上传失败时，生成记录保持成功，并回退保存上游 AI 临时 URL。
- [ ] 森络盘创建直链接口失败时，上传仍然成功并返回项目 `/api/files/:id/content` 地址。
- [ ] 删除对象时，森络盘直链和 WebDAV 文件均被清理。
- [ ] 重新登录或更换设备后，森络盘直链仍然能够读取图片。
- [ ] 已生成但尚未写入直链的 WebDAV 对象，在读取文件信息或图片任务状态时会尝试补齐森络盘直链。
- [ ] 历史保存为项目 `/api/files/:id/content` 地址的 WebDAV 对象，在读取文件信息或内容时会重新补齐森络盘直链，并避免回退到自身地址。
- [ ] 已缓存项目文件代理地址的图片或媒体，重新解析 `server:<id>` 时会刷新公开地址并优先使用森络盘直链。
- [ ] 画布展示、图片转换和远程图片上传优先请求森络盘直链，直链因跨域或访问失败时再使用项目图片代理。
- [ ] 森络盘 Access Token 有效时请求复用原令牌，不重复登录。
- [ ] Access Token 过期时使用 Refresh Token 获取新令牌，并保存新的 Access Token、Refresh Token 和过期时间。
- [ ] Refresh Token 失效时使用森络盘账号邮箱和密码登录，保存新令牌；邮箱和密码与 WebDAV 用户名、密码分别生效。
- [ ] 森络盘接口返回 401 或 403 时自动重新认证并重试一次；认证失败时上传仍保留 WebDAV 文件并回退项目文件接口。
- [ ] 个人配置和管理员配置点击“检查认证”后，通过森络盘容量接口确认 Access Token 有效，并显示容量与过期时间。
- [ ] Access Token 无效时，认证检查会自动刷新令牌或使用账号密码登录，界面显示认证已更新且响应中不包含令牌和密码。
- [ ] 个人配置在检查认证前修改 WebDAV 地址、远程目录或森络盘 API 地址时，不会把续期令牌写入旧配置；保存新配置后仍可继续自动认证。
- [ ] WebDAV 端点仅包含 `/dav` 时，森络盘直链使用对象键中的远程目录一次，不重复拼接目录前缀。

## 个人 API Key 渠道

- [ ] 管理员配置渠道地址、协议和模型后，个人 API Key 模式只显示模型选择与各渠道的 API Key 输入框。
- [ ] 同一渠道被多个默认模型使用时，只显示一个 API Key 输入框；不同渠道分别保存各自的 API Key。
- [ ] 登录账号保存配置后，在另一浏览器登录同一账号可以恢复模型选择和个人 API Key。
- [ ] 同一浏览器切换账号时，前一账号的个人 API Key 不会显示或用于后一账号；后一账号配置加载完成后使用各自保存的密钥。
- [ ] 登录账号退出后恢复当前浏览器的匿名个人渠道配置，账号密钥不会写入浏览器持久化配置。
- [ ] 管理员停用渠道、修改渠道地址或移除模型后，服务端调用采用最新渠道配置并返回对应提示。
- [ ] 管理员渠道未填写系统 API Key 时，个人 API Key 模式仍可通过该渠道发起请求。
- [ ] 管理员渠道未填写系统 API Key 时，该渠道不会出现在云端渠道候选中；补充系统 API Key 后可以用于云端请求。
- [ ] 管理员编辑渠道并勾选“保存时清除系统 API Key”后，原有系统 API Key 被清除，个人 API Key 模式仍可使用该渠道。
- [ ] 管理员关闭个人 API Key 渠道后，配置界面隐藏密钥输入区域，无法使用云端渠道的普通用户看不到可选模型。
- [ ] 管理员关闭个人 API Key 渠道后，服务端拒绝使用账号个人密钥发起的模型请求。
- [ ] 管理员关闭个人 API Key 渠道后，账号再次保存模型配置时会清除已有个人渠道密钥。
- [ ] 登录账号的模型配置读取失败时，配置界面显示错误状态；点击“重新读取”后能够恢复账号配置并继续保存。
- [ ] 登录账号保存独立本地渠道后，重新读取配置仍保留渠道协议、地址、API Key 和模型列表；旧的系统渠道个人 API Key 格式继续可用。

## xAI Grok 视频参考素材

- [ ] 使用 `grok-imagine-video` 直连 xAI 兼容渠道并上传单张参考图时，后端请求进入上游且不再返回“xAI 视频模型暂不支持参考素材”。
- [ ] 使用多张参考图时，后端转换为 xAI `reference_images` 请求并能创建视频任务。
- [ ] 使用参考视频或上传参考音频时，界面显示后端返回的明确错误信息。
